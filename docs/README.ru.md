Ping4Win Utils не даёт вашему Mac засыпать по требованию, отображает системные показатели, которые действительно важны, даёт мыши прокрутку в стиле Windows без вмешательства в настройки трекпада, и заменяет ⌘Tab на переключатель окон с настоящими миниатюрами.

100% нативный (SwiftUI + AppKit), двуязычный (ru / en-US), без Electron, без аналитики, без сетевых запросов.

> **О форке:** Это форк проекта поддерживается командой [Ping4Win](https://ping4win.com). Основной вклад этого форка — полная русская локализация (`ru`) и русскоязычная документация. Все оригинальные функции сохранены без изменений.

## Функции

### ⚡ Режим бодрствования

- Включается из панели, контекстного меню или глобальным сочетанием **⌃⌥⌘K**
- Сессии от 15 мин до 8 ч или бессрочно — с продлением на +15/+30/+60 мин
- Держит экран включённым или позволяет ему гаснуть, пока система не спит
- **Режим закрытой крышки**: MacBook продолжает работать с закрытой крышкой  
  (`pmset disablesleep` — автоматически отменяется при завершении сессии, выходе из приложения или после сбоя)
- **Опциональный режим без пароля**: правило `sudoers`, ограниченное командой `pmset disablesleep 0/1`, проверяется через `visudo -c`, удаляется в любой момент
- **Защита аккумулятора**: сессия завершается при падении заряда ниже порога
- Обратный отсчёт в строке меню и уведомления об окончании сессии

### 🌡️ Системный монитор

- **Температуры** CPU, GPU и аккумулятора — наиболее релевантные показания с каждого компонента прямо из SMC
- **Нагрузка на железо**: CPU % и GPU %
- **Давление памяти** со светофорным индикатором (зелёный = норма, жёлтый = внимание, красный = критично) + используемая/общая память
- Живая **скорость сети** (загрузка/отдача) с итогами сессии
- **Потребление питания**: что потребляет Mac, что даёт адаптер, ток батареи, здоровье и число циклов
- **Графики** истории CPU, GPU, памяти, сети, питания и батареи
- **Тест скорости интернета** по требованию из блока «Сеть»
- **Метрики в строке меню**: закрепите CPU, GPU, RAM, Сеть или Питание рядом с иконкой

### 🖱️ Прокрутка в стиле Windows

- Инвертирует **только колесо мыши** — трекпад сохраняет нативную прокрутку macOS
- Применяется мгновенно, без перезагрузки, без расширений ядра

### 🪟 Переключатель окон

- Заменяет **⌘Tab** сеткой, где каждое окно показано в виде живой миниатюры, а не просто иконки
- Несколько окон одного приложения отображаются по отдельности
- Удержите ⌘ и нажимайте Tab для переключения; Shift/← — назад; отпустите — переключить; **Q** — закрыть выделенное приложение; Esc — отмена
- Порядок соответствует реальной истории использования; анимированно; с поддержкой Mission Control и Spaces
- При отсутствии разрешения на запись экрана показывает иконки приложений

### 🔊 Микшер громкости по приложениям

- Регулировка громкости каждого приложения с аудиоподключением (CoreAudio process taps, macOS 14.4+)
- **Буст до 200%** для тихих видео или звонков — янтарный индикатор показывает активный буст
- Живой индикатор отмечает приложения, воспроизводящие звук сейчас; уровни сохраняются

### 🧰 Утилиты

- **Вырезание и вставка файлов в Finder** через ⌘X / ⌘V — плавающий HUD показывает удерживаемые элементы (включается отдельно)
- **Выход при закрытии последнего окна** с исключениями для отдельных приложений (включается отдельно)
- **Полный деинсталлятор приложений**: поиск и удаление кешей, настроек, логов, контейнеров (включается отдельно)
- **Временная полка**: место для хранения файлов, изображений, текста и ссылок в процессе перетаскивания — вызов через ⌃⌥⌘D или встряхивание мышью (включается отдельно)
- **Режим чистки**: блокировка клавиатуры для протирки — разблокируется через 60 с или пять нажатий одной клавиши
- Скрыть значки на рабочем столе, показать скрытые файлы в Finder, выключить дисплей, извлечь все диски, очистить корзину

## Установка

### Скачать (рекомендуется)

Загрузите последний DMG со страницы [**Releases**](https://github.com/Ping4Win/ping4win-utils/releases), откройте его и перетащите **Ping4Win Utils** в папку **Приложения**.

> Релизы подписаны ad-hoc (без платного сертификата Apple Developer). При первом запуске нажмите правой кнопкой на приложение → **Открыть**, или снимите флаг карантина:
> ```bash
> xattr -d com.apple.quarantine "/Applications/Ping4Win Utils.app"
> ```

### Сборка из исходников

```bash
git clone https://github.com/Ping4Win/ping4win-utils.git
cd ping4win-utils
./build.sh            # компиляция, генерация иконки, сборка подписанного бандла
./build.sh --install  # то же + установка в /Applications и запуск
```

### Требования

- macOS 14 (Sonoma) или новее
- Apple Silicon
- Xcode Command Line Tools (для сборки из исходников)

### Удаление

```bash
./Tools/uninstall.sh
```

Завершает приложение, отменяет регистрацию элемента входа, сбрасывает разрешения Accessibility и Screen Recording, удаляет приложение, настройки и сохранённое состояние, а также опциональное правило `sudoers` для закрытой крышки.

Или перетащите приложение в корзину и выполните:
```bash
tccutil reset All com.ping4win.utils
```

## Разрешения

Все разрешения опциональны — функции деградируют плавно, а онбординг проведёт по каждому из них:

| Разрешение | Используется | Без него |
|---|---|---|
| **Специальные возможности** | Инвертор прокрутки, обработка клавиатуры в switcher | Обе функции недоступны |
| **Запись экрана** | Названия и миниатюры окон в переключателе | Переключатель показывает только иконки |
| **Уведомления** | Оповещения об окончании сессии и защите аккумулятора | Тихая работа |
| **Администратор (один раз, опц.)** | Переключение закрытой крышки без пароля | Запрос пароля при каждом переключении |

При первом запуске открывается 7-шаговый онбординг (язык, разрешения, обзор монитора, дополнительные функции, проверка состояния). Вернуться к нему можно в любое время: **Настройки › О программе › Повторить введение**.

## Архитектура

```
Sources/Ping4WinUtils/
├── main.swift                  # точка входа (--selftest, --sensors)
├── App/                        # AppDelegate, элемент строки меню
├── Core/                       # локализация (ru / en-US), разрешения, defaults
├── Services/
│   ├── KeepAwakeManager.swift  # IOKit assertions, закрытая крышка, мониторинг батареи
│   ├── ScrollInverter.swift    # CGEventTap, инверсия только мыши
│   ├── SystemMonitor/          # клиент SMC, нагрузка CPU/GPU, давление памяти
│   ├── Switcher/               # перечисление, активация AX, превью SCK, tap
│   └── …                       # горячие клавиши, уведомления, shell-хелперы
├── Support/                    # selftest и дамп сенсоров
└── UI/                         # SwiftUI: панель, настройки, онбординг, switcher
```

Строгое разделение: **UI** наблюдает за **сервисами**; сервисы никогда не импортируют SwiftUI.  
Каждая строка интерфейса живёт в `Core/Localization.swift`, компилятор проверяет наличие переводов для обоих языков.

Диагностика:

```bash
"/Applications/Ping4Win Utils.app/Contents/MacOS/Ping4WinUtils" --selftest  # SELFTEST OK
"/Applications/Ping4Win Utils.app/Contents/MacOS/Ping4WinUtils" --sensors   # дамп сенсоров SMC
```
