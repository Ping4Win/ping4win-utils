Ping4Win Utils не дає вашому Mac засинати на вимогу, показує системні показники, які справді мають значення, додає миші прокрутку у стилі Windows без впливу на трекпад і замінює ⌘Tab перемикачем вікон зі справжніми мініатюрами.

100% нативний (SwiftUI + AppKit), двомовний (uk / en-US), без Electron, без аналітики, без мережевих запитів.

> **Про форк:** Це форк проєкту [vorssaint/vorssaint-utils](https://github.com/vorssaint/vorssaint-utils), який підтримує [Ping4Win](https://ping4win.com). Основний внесок цього форку — повна російська та українська локалізація і документація відповідними мовами. Усі оригінальні функції збережено без змін.

## Функції

### ⚡ Режим неспання

- Вмикається з панелі, контекстного меню або глобальним сполученням **⌃⌥⌘K**
- Сесії від 15 хв до 8 год або безстроково — з продовженням на +15/+30/+60 хв
- Тримати екран увімкненим або дозволити йому спати, поки система не спить
- **Режим закритої кришки**: MacBook продовжує працювати із закритою кришкою
  (`pmset disablesleep` — автоматично скасовується при завершенні сесії, виході з програми або після збою)
- **Опційний режим без пароля**: правило `sudoers`, обмежене командою `pmset disablesleep 0/1`, перевіряється через `visudo -c`, видаляється будь-коли
- **Захист акумулятора**: сесія завершується при падінні заряду нижче порога
- Зворотний відлік у рядку меню та сповіщення про закінчення сесії

### 🌡️ Системний монітор

- **Температури** CPU, GPU та акумулятора — найбільш релевантні показання для кожного компонента прямо із SMC
- **Навантаження на залізо**: CPU % та GPU %
- **Тиск пам'яті** зі світлофорним індикатором (зелений = норма, жовтий = увага, червоний = критично) + використана/загальна пам'ять
- Жива **швидкість мережі** (завантаження/відвантаження) з підсумками сесії
- **Споживання живлення**: що споживається, вхід адаптера, потік батареї, стан і кількість циклів
- **Графіки** історії CPU, GPU, пам'яті, мережі, живлення та батареї
- **Тест швидкості інтернету** на вимогу з блока «Мережа»
- **Метрики в рядку меню**: закріпіть CPU, GPU, RAM, Мережу чи Живлення поруч з іконкою

### 🖱️ Прокрутка у стилі Windows

- Інвертує **лише коліщатко миші** — трекпад зберігає природну прокрутку macOS
- Застосовується миттєво, без перезапуску, без розширень ядра

### 🪟 Перемикач вікон

- Замінює **⌘Tab** сіткою, де кожне вікно показано живою мініатюрою, а не просто іконкою
- Кілька вікон однієї програми відображаються окремо
- Утримуйте ⌘ і натискайте Tab для перемикання; Shift/← — назад; відпустіть — перемкнутися; **Q** — закрити виділену програму; Esc — скасувати
- Дотримується реального порядку нещодавнього використання; плавно, анімовано; сумісно з Mission Control і Spaces
- Коректно відкочується до іконок програм, якщо не надано доступ до запису екрана

### 🔊 Мікшер гучності по програмах

- Регулювання гучності кожної програми з аудіопідключенням (CoreAudio process taps, macOS 14.4+)
- **Підсилення до 200%** для тихих відео чи дзвінків — бурштиновий індикатор показує активне підсилення
- Живий індикатор відмічає програми, що відтворюють зараз; гучності зберігаються окремо

### 🧰 Утиліти

- **Вирізання і вставлення файлів у Finder** через ⌘X / ⌘V — плаваючий HUD показує утримувані елементи (вмикається окремо)
- **Вихід при закритті останнього вікна** з винятками для окремих програм (вмикається окремо)
- **Повний деінсталятор програм**: пошук і видалення кешів, налаштувань, логів, контейнерів (вмикається окремо)
- **Тимчасова полиця**: тримайте файли, зображення, текст і посилання посеред перетягування через ⌃⌥⌘D або струшування мишею (вмикається окремо)
- **Режим чистки**: блокування клавіатури для протирання — розблоковується через 60 с або п'ять натискань
- Сховати іконки робочого столу, показати приховані файли у Finder, вимкнути екран, відключити всі диски, очистити Кошик

## Встановлення

### Завантаження (рекомендовано)

Завантажте останній DMG зі сторінки [**Releases**](https://github.com/Ping4Win/ping4win-utils/releases), відкрийте його та перетягніть **Ping4Win Utils** у **Програми**.

> Релізи підписані ad-hoc (без платного сертифіката Apple Developer). При першому запуску клацніть програму правою кнопкою → **Відкрити**, або зніміть прапорець карантину:
> ```bash
> xattr -d com.apple.quarantine "/Applications/Ping4Win Utils.app"
> ```

### Збірка з вихідних кодів

```bash
git clone https://github.com/Ping4Win/ping4win-utils.git
cd ping4win-utils
./build.sh            # компіляція, генерація іконки, збирання підписаного бандла
./build.sh --install  # те саме + встановлення в /Applications і запуск
```

### Вимоги

- macOS 14 (Sonoma) або новіша
- Apple Silicon
- Xcode Command Line Tools (для збірки з вихідних кодів)

### Видалення

```bash
./Tools/uninstall.sh
```

Завершує програму, скасовує реєстрацію елемента входу, скидає дозволи Accessibility і Screen Recording, видаляє програму, налаштування та збережений стан, а також прибирає опційне правило `sudoers` для закритої кришки — не лишаючи нічого по собі.

Або перетягніть програму в Кошик і виконайте:
```bash
tccutil reset All com.ping4win.utils
```

## Дозволи

Усе опційне — функції коректно деградують, а онбординг проведе вас через кожен дозвіл:

| Дозвіл | Використовується для | Без нього |
|---|---|---|
| **Accessibility** | Інвертер прокрутки, обробка клавіатури в перемикачі | Обидві функції вимкнені |
| **Screen Recording** | Назви та мініатюри вікон у перемикачі | Перемикач показує лише іконки |
| **Сповіщення** | Оповіщення про кінець сесії та захист батареї | Тиха робота при кожному перемиканні |
| **Адміністратор (один раз, опц.)** | Перемикання закритої кришки без пароля | Запит пароля при кожному перемиканні |

При першому запуску відкривається 7-кроковий онбординг (мова, дозволи, огляд монітора, додаткові функції, перевірка стану). Повернутися до нього можна будь-коли: **Налаштування › Про програму › Повторити введення**.

## Архітектура

```
Sources/Ping4WinUtils/
├── main.swift                  # точка входу (--selftest, --sensors)
├── App/                        # AppDelegate, елемент строки меню
├── Core/                       # локалізація (uk / ru / en-US), дозволи, defaults
├── Services/
│   ├── KeepAwakeManager.swift  # IOKit assertions, закрита кришка, моніторинг батареї
│   ├── ScrollInverter.swift    # CGEventTap, інверсія тільки миші
│   ├── SystemMonitor/          # клієнт SMC, навантаження CPU/GPU, тиск пам'яті
│   ├── Switcher/               # перечислення, активація AX, прев'ю SCK, tap
│   └── …                       # гарячі клавіші, сповіщення, shell-хелпери
├── Support/                    # selftest і дамп сенсорів
└── UI/                         # SwiftUI: панель, налаштування, онбординг, switcher
```

Сувора відокремленість: **UI** спостерігає за **сервісами**; сервіси ніколи не імпортують SwiftUI.
Кожен рядок інтерфейсу живе у `Core/Localization.swift`, компілятор перевіряє наявність перекладів для всіх мов.

Діагностика:

```bash
"/Applications/Ping4Win Utils.app/Contents/MacOS/Ping4WinUtils" --selftest  # SELFTEST OK
"/Applications/Ping4Win Utils.app/Contents/MacOS/Ping4WinUtils" --sensors   # дамп сенсорів SMC
```
